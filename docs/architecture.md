## 组件说明

### 1. Coze Bot（智能体）

- **平台**：Coze (coze.cn)
- **名称**：热点情报雷达
- **模型**：豆包 1.8 深度思考
- **模式**：单 Agent（自主规划模式）
- **挂载插件**：热点情报雷达（自定义插件，调用工作流 API）
- **交互方式**：用户通过自然语言对话触发采集任务

### 2. Coze 插件

- **名称**：热点情报雷达
- **类型**：自定义插件
- **功能**：封装工作流 API 调用
- **工具**：`run_hotspot_radar`
- **端点**：`POST /async_run`
- **鉴权**：Bearer Token

### 3. 工作流（Workflow）

- **部署平台**：Coze 扣子编程 (code.coze.cn)
- **部署方式**：Web 服务
- **输入**：keywords / recipient_email / trigger_type
- **输出**：report_html / email_status / 统计数据
- **执行时间**：约 5-10 分钟

### 4. 定时触发（CodeAct + Calendar）

- **触发方式**：Coze Calendar 每日定时触发
- **脚本**：`hotspot_daily_trigger.py`（CodeAct 脚本）
- **执行时间**：每天 08:00-08:30（浮动窗口）
- **逻辑**：读取配置 → 调用工作流 API → 记录结果

### 5. 邮件推送

- **触发条件**：工作流执行完成后自动发送
- **格式**：HTML 内嵌邮件
- **内容**：热点分析报告（S/A 级热点详情 + 来源链接 + 风险提示）

## 数据流

```
关键词 → 搜索 API → 原始数据 → 清洗去重 → 事件簇 → AI 评分 → HTML 报告 → 邮件
```
